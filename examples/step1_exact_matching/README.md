# Step 1 worked example

Runnable companion to [the Step 1 guide](../../docs/guide_step1_exact_matching.md).
All codes (`RXN-…`, `UNII-…`) and some names are invented to show behaviour; they are
not real terminology content.

```bash
pip install -e ".[lexicon]"   # from the repository root
./examples/step1_exact_matching/run.sh
```
